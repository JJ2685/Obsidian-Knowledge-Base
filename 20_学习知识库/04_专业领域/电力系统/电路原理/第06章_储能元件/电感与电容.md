# 电感与电容

## 0. 一句话理解
电容储存电场能量（电压与电荷挂钩），电感储存磁场能量（电流与磁链挂钩），二者在数学形式上完全对偶，且都是"记忆元件"——当前状态取决于过去的全部历史。

## 1. 为什么需要它
- 电网里有大量储能元件（线路电容、变压器电感），暂态分析全靠它们。
- 没有它们，正弦交流电路与暂态分析无从谈起（直流稳态下它们退化为开路/短路）。
- 是后续第 7 章（时域分析）、第 8/9 章（相量法）的前置。

## 2. 基本概念
- **电容**：储存电荷（电场能量）的二端元件。线性电容 $q = Cu$，$C$ 单位为法拉（F），$1\,\mathrm{F} = 1\,\mathrm{C/V}$。
- **电感**：储存磁链（磁场能量）的二端元件。线性电感 $\Psi = Li$，$L$ 单位为亨利（H），$1\,\mathrm{H} = 1\,\mathrm{Wb/A}$。

## 3. 工作原理（伏安关系，关联参考方向）
电容：
$$i = \frac{dq}{dt} = C\frac{du}{dt}$$
电感：
$$u = \frac{d\Psi}{dt} = L\frac{di}{dt}$$

主要性质：
- **动态元件**：电容电流取决于电压变化率，直流稳态时 $i=0$（相当于**开路**）；电感电压取决于电流变化率，直流稳态时 $u=0$（相当于**短路**）。
- **记忆元件**：$u(t) = u(t_0) + \dfrac{1}{C}\int_{t_0}^{t} i(\xi)\,d\xi$；$i(t) = i(t_0) + \dfrac{1}{L}\int_{t_0}^{t} u(\xi)\,d\xi$。
- **不能跃变**：电流有界则电容电压连续（$u(0_+) = u(0_-)$）；电压有界则电感电流连续。
- **无源元件**：储能 $w_C = \frac{1}{2}Cu^2 \ge 0$、$w_L = \frac{1}{2}Li^2 \ge 0$，只吞吐能量、不消耗能量。

## 4. 结构、组成或关键参数
| 名称 | 含义 | 作用 | 注意事项 |
|---|---|---|---|
| $C$ | 电容（F） | 储存电场能量 | 直流稳态 = 开路 |
| $L$ | 电感（H） | 储存磁场能量 | 直流稳态 = 短路 |
| 时间常数 | $\tau=RC$ / $\tau=L/R$ | 暂态衰减快慢 | 第 7 章深入 |

## 5. 示例
### 直观示例
电容像水箱：水位（电压）不能突变，进出水流（电流）决定水位变化速度。电感像水流的惯性（水锤效应）：流量（电流）不能突变。

### 技术示例（对偶关系）
$$q = Cu \leftrightarrow \Psi = Li,\quad i = C\frac{du}{dt} \leftrightarrow u = L\frac{di}{dt}$$
$$w_C = \frac{1}{2}Cu^2 \leftrightarrow w_L = \frac{1}{2}Li^2,\quad 开路 \leftrightarrow 短路,\quad 电压连续 \leftrightarrow 电流连续$$

- 实际使用前置：微积分基础（[[Δ与微分]]、[[积分与求和]]）。

## 7. 常见误区与易混淆概念
| 容易混淆的内容 | 区别 | 记忆方法 |
|---|---|---|
| 电容 vs 电感 | 电场储能 vs 磁场储能 | 对偶：C↔L、u↔i 互换 |
| 直流稳态行为 | 电容开路 / 电感短路 | "隔直通交"（电容） |
| 谁能跃变 | 电压（电容）不能 / 电流（电感）不能 | 记忆元件特性 |

## 8. 常见问题与排查
| 现象 | 可能原因 | 检查方法 | 处理方向 |

## 11. 最终记忆卡片
- **核心结论**：电容 $i=C\frac{du}{dt}$、电感 $u=L\frac{di}{dt}$，互为对偶，都是记忆元件。
- **必须记住的 3 点**：
  1. 直流稳态：电容开路、电感短路。
  2. 电容电压、电感电流不能跃变。
  3. 储能 $w_C=\frac{1}{2}Cu^2$、$w_L=\frac{1}{2}Li^2$，无源不耗能。
- **仍需确认的内容**：教材具体页码；第 7 章时间常数应用。
