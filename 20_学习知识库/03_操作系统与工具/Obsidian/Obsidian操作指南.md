# Obsidian 操作指南

## 0. 一句话理解
Obsidian 日常记笔记的简明速查：快捷键、格式、双链、标签、图谱、MOC 与 Canvas。快捷键以 Windows 为准（macOS 把 Ctrl 换成 Cmd）。

## 1. 快捷键
| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` / `Ctrl+O` | 新建笔记 / 快速打开（输入名字回车） |
| `Ctrl+P` | 命令面板（忘记功能在哪就搜） |
| `Ctrl+Shift+F` | 全文搜索 |
| `Ctrl+F` / `Ctrl+H` | 当前笔记查找 / 替换 |
| `Ctrl+E` | 切换编辑/阅读视图 |
| `F2` | 重命名笔记（链接自动更新） |
| `Ctrl+B` / `Ctrl+I` | 粗体 / 斜体 |
| `Ctrl+K` | 插入链接 |
| `Ctrl+G` | 打开关系图谱 |
| `Ctrl+Enter` | 勾选/取消任务复选框 |

## 2. 常用格式
| 格式 | 写法 |
| --- | --- |
| 高亮 | `==重点==` |
| 删除线 | `~~删除~~` |
| 行内代码 | `` `代码` `` |
| 任务 | `- [ ]` / `- [x]` |
| 提示框 | `> [!tip] 标题` + `> 内容`（常用：note、tip、warning、danger、example、quote） |
| 隐藏内容 | `%%注释%%` |

> 一篇笔记只用一个 `#` 一级标题，正文用 `##`、`###` 分层（大纲和图谱靠标题层级工作）。

## 3. 链接笔记
```markdown
[[另一篇笔记]]               链接
[[另一篇笔记|显示文字]]      改显示文字
[[另一篇笔记#某个标题]]      跳到某节
![[另一篇笔记]]              嵌入整篇
![[图片.png|400]]            嵌入图片并定宽
```
- 输入 `[[` 自动补全；给段落加块 ID（段末 ` ^id`）可被精确引用。

## 4. 标签与属性
- **标签**：正文里 `#主题`，支持层级 `#读书/小说`，用于跨文件夹分类。
- **属性**：笔记顶部三横线之间记录元数据；属性值为 `[[链接]]` 时加英文引号。
- 本库的属性规范见 [[02_命名与属性规范]]。

## 5. 关系图谱与 MOC
- `Ctrl+G` 全局图谱：检查知识网络断点、发现孤立笔记。
- **MOC（内容地图）**：某主题积累到十篇以上时，建一篇纯索引笔记串起同主题笔记（只放链接和一句话说明）。本库的索引笔记如 [[00_课程章节索引]]、[[00_电力系统知识地图]]。

## 6. Canvas（白板）
- 左侧文件列表右键 → 新建 Canvas：无限画布，可把笔记卡片、文字、图片自由摆布并连线。
- 与 MOC 的区别：MOC 是线性文字目录，Canvas 是空间化思维图。
- 典型场景：梳理论文框架、画项目流程、做主题知识地图。

## 7. 日常习惯建议
- 一篇笔记只讲一件事，用链接把零散想法串起来。
- 文件夹只做粗分类，细分交给标签和 MOC。
- 附件统一放一个文件夹（本库：`90_附件`）。
- 定期看一次图谱，给孤立笔记补链接或归档。
- 所有内容都是本地 .md 文件，用 Git 或网盘做备份（本库已用 Git + GitHub 私有仓库）。
