# DeepTutor 学习工作流

## 0. 一句话理解
用 DeepTutor 学、仿真软件验证、Obsidian 积累——每个知识点按"选目标 → 找资料 → 分步讲解 → 自己作答 → 仿真验证 → 写笔记 → 复习"的循环推进。

## 1. 四种主要用法

| 用法 | 入口 | 适合场景 |
|---|---|---|
| A. 精读教材（Immersive Reading） | Personalized Learning → Immersive Reading | 只学一份教材/手册/论文 |
| B. 跨资料检索（Knowledge Center） | Learning Space → Knowledge Center | 问题需综合多份资料 |
| C. 系统化学习（Mastery Path） | Personalized Learning → Mastery Path | 按顺序学习、做题、检查掌握程度 |
| D. 普通 Chat | 对话 + 附加文件 | 单概念讲解、排查、出题、整理笔记 |

## 2. 学习循环（每个知识点）

1. **选一个小目标**：例如"理解母线电压和相角"，不要一次学完整章。
2. **找资料**：先 Immersive Reading 精读教材；跨资料用 Knowledge Center。
3. **分步讲解**：先概念 → 公式 → 简单例子，一次只讲一个知识点。
4. **自己作答**：让它出题，先自己答再看答案。
5. **仿真验证**：BPA / Simulink / PSCAD 实操，保存输入文件、日志、截图。
6. **写 Obsidian 笔记**：只记录理解过的内容；未验证标注"待验证"（用 [[学习-知识点笔记]] 模板）。
7. **笔记复习**：把笔记交给 DeepTutor 出题检查掌握程度。

**完成标准**：能用自己的话解释、能完成一道练习、能指出资料来源；涉及软件还要能复现操作并解释结果。

## 3. 每日学习流程（60~120 分钟）

| 任务 | 时长 | 产出 |
|---|---|---|
| 确定目标 | 2 分钟 | 一个小知识点 |
| 找依据 | 10~15 分钟 | 教材/知识库定位 |
| 学习提问 | 20~30 分钟 | 概念 + 公式 + 一道题 |
| 实操 | 20~45 分钟 | 真实运行记录 |
| 写笔记 | 10~15 分钟 | 一篇笔记 |
| 复习 | 5 分钟 | 掌握程度判断 |

## 4. 可复用的提示词

**长期教学规则**（核心）：
```text
你是我的电力系统仿真学习导师。我是计算机本科，电气基础较弱，正在学习电力系统分析、BPA、MATLAB/Simulink 和 PSCAD。

请遵守：
1. 优先使用我选中的知识库或附加资料；引用时尽量注明文件名、章节、页码。
2. 不要默认我懂电路、电气符号或电力系统术语。
3. 每次只讲一个知识点：先类比，再定义，再公式，再工程例子。
4. 解释公式的所有符号、单位、物理意义和适用条件。
5. 区分资料明确记载、合理推断和待验证内容。
6. 软件操作一次只给一个主要步骤，说明操作目的、预期结果和失败时要提供的截图/日志。
7. 不要虚构软件按钮、许可证状态、计算结果或资料页码。
8. 每次给我一道小题，先等我作答再讲答案。
9. 最后总结本次成果、未解决问题和下一步任务。
```

**整理为 Obsidian Markdown**：
```text
请把本次学习内容整理成可直接保存到 Obsidian 的 Markdown 笔记。
要求：标题清晰；包含一句话理解、专业定义、公式和单位、简单例子、常见误区；
软件操作记录版本/步骤/输入/输出/验证依据；用 [[概念名称]] 关联相关笔记；
参考来源写真实文件名、章节和页码；区分"已理解""已实际验证""待验证"；
不要虚构页码、数据和仿真结果；最后列出 3 道复习题及下一步建议。
```

## 5. 常见问题

- **找不到本地文件**：确认功能支持文件上传/工作区读取/文件夹链接；映射目录 ≠ 已索引。
- **知识库回答不准**：检查文件提取状态、选中的知识库；用能在原文定位的问题测试；扫描 PDF 需 OCR。
- **数据隐私**：不要把公司内部模型、真实工程数据、许可证文件、密钥发到未经授权的云服务。
