# 学习知识库入口

> 章节组织路径，知识点承载内容，实践笔记检验理解。

## 分区说明

| 目录 | 用途 |
|---|---|
| `01_计算机基础` | 计算机组成原理、操作系统、计算机网络、数据结构与算法 |
| `02_开发技术栈` | Java、Spring、MySQL、Docker、Qt、Python、MATLAB |
| `03_操作系统与工具` | Linux、Windows、Git、Vim、SSH、Obsidian |
| `04_专业领域` | 电力系统：电路原理、电力系统分析、电力电子技术、电机学；数学基础 |
| `05_学习实践与实验` | Java项目实践、Linux实验、Qt编译实验、BPA仿真实验 |

## 笔记组织方式

- 技术栈/课程目录作为入口，知识点笔记作为实际内容。
- 一本书/一门课：先建章节索引（如 [[00_课程章节索引]]），每章一篇章节笔记，知识点拆成独立笔记。
- 一个知识点只保留一篇主笔记，其他位置用双链引用，不复制多份。
- 技术栈地图（如 [[00_Java技术栈地图]]）只说明学习路线、核心模块和笔记链接，不重复讲解知识点。

## 快速开始

- 新课程/技术栈：先建技术栈地图或章节索引
- 每章：用 [[学习-章节笔记]] 模板
- 每个概念：用 [[学习-知识点笔记]] 模板
- 动手实践后，把结果补充进对应笔记并更新掌握状态
