# 凝思服务器环境基线

> 用途：排查问题时对照的系统/网络/软件基线。不含密码、密钥。

## 1. 系统与硬件

| 项 | 值 |
|---|---|
| 系统 | 凝思安全操作系统 V6.0.8（Debian 8 / glibc 2.19），内核 4.9.0-8-linx-security-amd64 |
| CPU | 海光 C86-3350（Zen 架构）× 16 核 |
| 内存 | 15GB |
| 显卡 | NVIDIA GT 730（GK208），PCI 05:00.0，nouveau 驱动（硬件 GL） |
| 桌面 | lightdm + MATE |
| 安全模块 | linx_sec（序列号校验：eth0 接口 MAC 必须等于绑定 MAC） |

## 2. 网络（2026-11-02 网络重构后）

| 网口 | 硬件 / MAC | 配置 | 状态 |
|---|---|---|---|
| eth0 | 板载 yt6801 / `1c:83:41:f5:00:c7` | 192.168.0.250/24，网关 .1，DNS 114.114.114.114 / 180.76.76.76 | ✅ 管理 + 数据通信共用，1000Mb/s |
| eth1 | PCIe RTL8168 / `00:e0:4c:e6:40:a1` | 192.168.1.250/24（配置保留） | ❌ 未接网线，弃用 |

- 数据通信网关：`192.168.0.252`（MAC `98:0e:24:d4:79:ba`），可 ping（0.3ms）。
- 开机网络自愈：initramfs 时序修复 + ensure-eth0.service（见 [[RB-Linux-凝思开机网络自动恢复]]）。
- 防火墙：仅放行 `192.168.0.252` 的 UDP 11002 入向（`/etc/iptables.up.rules` + rc.local 持久化）。

## 3. 软件运行环境

| 项 | 路径 / 值 |
|---|---|
| Qt 运行库（实际使用） | `/opt/Qt5.15.2/`（含 WebEngine、qt.conf） |
| Qt 运行库（备用） | `/opt/Qt5.12.12/` |
| 补齐系统库 | `/opt/qt-runtime-lib/`（xkbcommon、stdc++ 12.2、dbus、xcb-util、xcb-xinerama） |
| 生产程序 | `/opt/tn-frequency-v2/{bin,html,tn-frequency.sh,src}` |
| 渲染兜底 | `GALLIUM_DRIVER=softpipe`（国产 CPU 必需） |
| 编译环境 | 服务器无法编译（Qt 商用许可）；用 CentOS 7 VM + Docker Ubuntu 20.04（qtwebengine5-dev） |
| 远程登录 | SSH 22，别名 `linx`，ed25519 + 旧算法兼容（Windows ~/.ssh/config） |

## 4. 序列号与授权

- `linx_serial=17508BDE49415576`（grub 参数），绑定 eth0 MAC `1C8341F500C7`（`get_linxsninfo -s` 可查）。
- 弹授权窗 = checksn 校验失败（时序问题已根治，见 [[INC-20261030-Linx-序列号弹窗与重启断网]]）。
- 禁止自行修改 `/etc/default/grub` 中的 linx_serial。
