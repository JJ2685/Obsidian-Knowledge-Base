# 环境与部署

> 本文记录当前生效的服务器环境基线与部署配置。账号密码不在此记录（由管理员提供）。

## 1. 服务器环境

| 项 | 值 |
|---|---|
| 系统 | 凝思安全操作系统 V6.0.8（Debian 8 / glibc 2.19），内核 4.9.0-8-linx-security-amd64 |
| CPU / 内存 | 海光 C86-3350（Zen 架构）× 16 核 / 15GB |
| 显卡 | NVIDIA GT 730（GK208，PCI `05:00.0`），nouveau 驱动 |
| 管理 IP | eth0 = `192.168.0.250/24`，网关 192.168.0.1，DNS 114.114.114.114 / 180.76.76.76 |
| 数据网口 | eth1 已弃用（未接网线）；数据通信走 eth0 网段 |
| 序列号 | `linx_serial=17508BDE49415576`，绑定板载网卡 MAC `1c:83:41:f5:00:c7` |
| 远程登录 | SSH（22），别名 `linx`，ed25519 密钥 + 旧算法兼容参数 |

## 2. 程序部署（生产）

```
/opt/tn-frequency-v2/
├── bin/
│   ├── tn_frequency    # 编译产物（162KB，Qt 5.12.8 编译）
│   └── config.ini      # 与 exe 同目录（UdpServerIP=192.168.0.252）
├── html/               # 完整监控界面（171 个文件，layui + echarts）
├── tn-frequency.sh     # 启动脚本（Qt 5.15.2 运行库 + softpipe）
└── src/                # 新版源码（含 appconfig）
```

启动方式：`DISPLAY=:0 /opt/tn-frequency-v2/tn-frequency.sh`（首次完整渲染约 45 秒）

## 3. config.ini（当前生效）

```ini
[UdpConfig]
UdpServerIP=192.168.0.252   ; 数据通信网关 IP（命令发往此处）
UdpServerPort=11001         ; 网关命令监听端口
UdpListenIP=0.0.0.0         ; 工作站监听地址（所有网卡）
UdpListenPort=11002         ; 工作站接收实时数据端口
```

## 4. 数据通信网关（192.168.0.252）

| 参数 | 配置值 | 说明 |
|---|---|---|
| 上报目标 IP | `192.168.0.250` | 工作站 eth0（注意是 0.250） |
| 上报目标端口 | `11002`（UDP） | 工作站实时数据监听端口 |
| 命令接收端口 | `11001`（UDP） | 接收工作站投运开关等命令 |

**当前待办（网关侧）**：配置数据上报目标；导出 NFS 共享（/DataOut、/LoBoTest、/opt/Template、/PfreqCnf、/opt/logo），工作站侧 fstab 已备好注释版挂载段。

## 5. 工作站侧系统配置（已落地）

- **防火墙**（已持久化 `/etc/iptables.up.rules`）：
  ```
  -A INPUT -s 192.168.0.252/32 -p udp -m udp --dport 11002 -j ACCEPT
  -A INPUT -p udp -m udp --dport 11002 -j DROP
  ```
- **开机网络自愈**：initramfs 时序修复 + `ensure-eth0.service` 兜底（见 [[RB-Linux-凝思开机网络自动恢复]]）。
- **Qt 运行库**：`/opt/Qt5.15.2/`（实际使用）、`/opt/Qt5.12.12/`（备用）、`/opt/qt-runtime-lib/`（补齐系统库）。
- **启动脚本要点**：`LD_LIBRARY_PATH` 指向 Qt5.15.2 + qt-runtime-lib；`GALLIUM_DRIVER=softpipe`（国产 CPU 必需）；`QTWEBENGINE_CHROMIUM_FLAGS="--no-sandbox --disable-gpu"`。

## 6. 换机部署必改清单

| 优先级 | 项 | 改动内容 |
|---|---|---|
| 必改 | `bin/config.ini` | `UdpServerIP` 改为新数据端 IP（四项非空合法） |
| 必改 | `tn-frequency.sh` | Qt 运行库路径、程序绝对路径 |
| 视情况 | 防火墙 | 放行新数据端来源的 UDP 11002 |
| 视情况 | 源码硬编码路径 | 录波目录若不同需改 `mainwindow.cpp` 并重编译（优先 NFS 同名挂载规避） |
| 一般不改 | 前端 js | `ws://localhost:2018` 界面桥 |
| 国产 CPU 保留 | `GALLIUM_DRIVER=softpipe` | 海光/兆芯必需；普通 x86 可删 |

## 7. 远程操作禁忌

- 不要执行 `pkill -f tn_frequency`（会杀掉当前 SSH shell），用 `pkill -x tn_frequency`。
- 不要远程执行 `systemctl restart lightdm`（会结束现场图形会话）。
- 监控界面不是网页服务，不能用浏览器打开 `http://192.168.0.250`。
