# 项目背景与架构

## 1. 系统组成

本系统由**两个程序**组成，当前部署在同一台凝思工作站上：

| 程序 | 角色 | 现状 |
|---|---|---|
| tn_frequency | GUI 工作站程序（Qt + QWebEngine 内嵌前端） | 生产运行（v2 改造版，/opt/tn-frequency-v2/） |
| Reqlian_frequency | 数据/控制后台（采集、录波、UDP） | 旧版数据端，2026-11-02 清理时从服务器移除（程序合一运行） |

## 2. 系统架构

```
┌─────────────────────────── 工作站（凝思服务器） ───────────────────────────┐
│   tn_frequency (Qt GUI)                                                    │
│   ├─ QWebEngineView 内嵌浏览器 ──加载 ../html/index.html ──┐                 │
│   ├─ QWebSocketServer :2018 (LocalHost) ◀── QWebChannel(WebSocket) ──┘ 界面桥│
│   ├─ 读 /DataOut/*.csv → csvread 分析（录波历史）                            │
│   └─ QUdpSocket                                                             │
│        ├─ bind 0.0.0.0:11002 ◀── 实时数据（来自网关）                        │
│        └─ send 192.168.0.252:11001 ──▶ 控制命令（投运开关等）                │
└────────────────────────────────────────────────────────────────────────────┘
```

**关键判断**：WebSocket :2018 是"浏览器↔Qt 后端"的界面桥，两者同在 GUI 进程内，必须保持 LocalHost；真正跨机的是 UDP 11001/11002 与 CSV 录波目录。

## 3. 数据流详情

- **实时数据/控制通道（UDP）**：GUI 收 `udp_read_data()` → `QtSendReal()` → 前端 `RealChanged` 信号 → echarts 曲线；前端 `WebSendMessage` 的 `cmd=120` → `udp_send_data()` → 网关。
- **录波文件（CSV）**：目录宏硬编码——`FILE_DIR=/DataOut/`（录波历史）、`TIG_FILE_DIR=/LoBoTest/`（手动触发）、`TEMP_FILE_DIR=/opt/Template/`（模板）、`CONFIG_FILE_PATCH=/PfreqCnf/config`（业务配置）、`LOGO_FILE_PATCH=/opt/logo/tn_frequency.logo`（日志）。跨机部署靠 NFS 挂载到同名路径。
- **前端 ↔ Qt（QWebChannel）**：前端 `html/js/*.js` 均 `ws://localhost:2018`；协议 `WebSendMessage(text)`（JS→Qt）、`MessageChanged`/`RealChanged`（Qt→JS）。

## 4. 版本演进

| 版本 | 说明 | 状态 |
|---|---|---|
| tn_frequency（2018 原始源码） | UDP 端点硬编码 LocalHost，无配置机制 | 改造基线 |
| tn_frequency_change_qt5.12 | 废弃分支：加 appconfig + config.ini，Windows + Qt6/MSVC 环境编译 | ❌ 废弃 |
| tn_frequency v2（appconfig 改造版） | 2018 原版 + 新增 appconfig 机制（UDP 四参数可配置）+ config.ini | ✅ 生产运行 |

废弃分支的详细分析与改造文档见：[[tn_frequency远程化改造方案审查（废弃）]]、[[tn_frequency废弃改造分支-代码改动与依据]]。

## 5. 改造要点（v2 版）

- 新增 `appconfig.h/cpp`：UDP 四参数（UdpServerIP/Port、UdpListenIP/Port）配置读写。
- `config.ini` 与可执行文件同目录，`applicationDirPath()` 定位（不依赖 CWD）。
- 四键缺失/非法时 `qCritical` 报错并重写默认值，杜绝静默回退 127.0.0.1。
- UDP 接收循环处理积压数据报，bind/send 检查返回值。
- 未改动：WebSocket 2018 界面桥、前端连接地址、录波目录宏。
